Club sign-ups, flawed on purpose (Chapter 3, Data Detective). TEACHER KEY: this file lists every planted flaw.
120 rows, 14 columns: student_id, first_name, surname, date_of_birth, year_group, gender, home_eircode, interests, club_choice, signup_date, attendance_pct, parent_phone, inferred_income_band, notes.
Purpose the school states for the data: assign students to after-school clubs.

Everything here is synthetic. First names are common Irish names; surnames come from a fixed list of obviously
fictional ones (Sampleton, Testerson, Mockwell, Fakeham, Dummyford, Exampleby, Stubbington, Placeholder, Specimen, Fixture, Draftly, Proofer). Eircodes use the routing key Z + two digits, which is not a real routing
key. Phone numbers use the prefix 080, which is not allocated to any Irish operator. Notes are invented.

Planted flaws and where to find them:
- Missing values: 9 rows with no club_choice, 6 rows with no year_group, 3 rows with blank interests.
- Inconsistent formats: signup_date in three styles (2026-09-03: 40 rows; 03/09/2026: 39 rows; 3 Sept 2026: 41 rows).
  year_group spelt four ways for the same year: TY (48), Transition Year (14), 4 (12), ty (10).
- Duplicates: 4 exact duplicate rows (S1051, S1078, S1069, S1046) and 2 near-duplicates that differ only in letter case and carry a new student_id, so only a name plus date_of_birth match finds them (S1080, S1043).
- Suspicious values: attendance_pct contains 104, -5 and n/a (one row each); every other value is 55-100.
- Imbalance: club_choice = Coding has 25 rows and 88% of them are Male (22 of 25). Every Coding row is Transition Year.
  Overall 84 of 120 rows (70%) are Transition Year; the other year groups have between 3 and 9 rows each.
- Sensitive or unnecessary for the stated purpose: home_eircode, parent_phone, date_of_birth, inferred_income_band, notes. inferred_income_band was never collected from anyone; it is a guess. notes holds free-text judgements about students (35 rows).

club-signups-cleaned-template.csv has the same header minus home_eircode, parent_phone, date_of_birth, inferred_income_band, notes, with empty rows, for students who prefer a spreadsheet.
